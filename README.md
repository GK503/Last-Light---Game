# Last-Light---Game
kinda tower defense game

## Prerequisites (Windows 11)

### 1. GraalVM
Install GraalVM and set `JAVA_HOME` to the GraalVM installation directory.

### 2. Visual Studio Build Tools (2026)
Install:
- C++ Build Tools (MSVC)
- Windows 11 SDK
- CMake tools

### 3. Git for Windows
Required for the `patch` utility used by GraalPy.

### 4. PATH
Add Git to PATH (so `patch` is available):

`C:\Program Files\Git\usr\bin`
